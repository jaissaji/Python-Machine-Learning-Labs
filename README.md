# Python & Machine Learning Labs

Coursework portfolio for Python, Data Science, Machine Learning, PCA, Clustering, ANN, and NLP.

1. Python Basics
2. NumPy
3. Pandas
4. Titanic
5. Classification
6. Heart Failure Analysis
7. Decision Tree
8. KNN
9. SVM
10. K-Means Clustering
11. PCA
12. Missing Data
13. Feature Engineering
14. Artificial Neural Networks
15. NLP Text Preprocessing
16. NLTK

Each topic has its own folder. Put the completed Google Colab/Jupyter `.ipynb` file in the matching folder.

## Good notebook structure

- Objective
- Dataset and source
- Imports
- Data loading
- Data cleaning/preprocessing
- Analysis/model
- Evaluation
- Results/plots
- Short conclusion

Do not upload passwords, API keys, or other private credentials.
